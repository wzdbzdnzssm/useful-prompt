**Input / 输入:** Material:
[Paste notes, logs, or code snippets]

**Expected result / 预期结果:** Structured documentation, missing items, and open questions

**When to use / 使用时机:** Use when existing docs, code, and operations notes need to be reconciled for a new maintainer.

**Completion / 完成标准:** Structured documentation, missing items, and open questions

### Prompt / 提示词

```text
Turn the material below into English documentation for a new maintainer. Preserve established facts and do not invent information. Cover: objective, how to run the project, key modules, configuration, common operations, and known limitations. Mark claims with insufficient evidence as “To confirm,” and finish with a list of sources that still need to be provided.

Material:
[Paste notes, logs, or code snippets]
```
