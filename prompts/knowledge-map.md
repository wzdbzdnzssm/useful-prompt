Organize scattered project material into navigation that answers a reader’s real questions.

[Paste files, links, and short descriptions]

**Expected result / 预期结果:** A knowledge map, each entry’s purpose and source, plus missing or stale material.

**When to use / 使用时机:** Organize scattered project material into navigation that answers a reader’s real questions.

**Completion / 完成标准:** A knowledge map, each entry’s purpose and source, plus missing or stale material.

### Prompt / 提示词

```text
Use the project material below to make a knowledge map for 【target readers】. Organize it by questions readers need to answer, not file names. For every entry, state what it answers, what to read first, where the source file or link is, and whether it is confirmed. Do not copy documents; mark missing evidence or conflicts as “To confirm,” then list the valuable gaps.

Material list:
[Paste files, links, and short descriptions]
```

## 中文

把散落的项目资料按读者问题整理成可用的导航入口。

[View on Reset / 在网站查看](https://reset.skill2web.com/zh/prompts/knowledge-map/?utm_source=github&utm_medium=referral&utm_campaign=useful_prompt&utm_content=knowledge_map_zh)

**Tool / 工具:** 通用

**Input / 输入:** 资料清单：
[粘贴文件、链接和简要说明]

**Expected result / 预期结果:** 资料导航、每项用途与来源位置，以及缺失或过期材料清单。

**When to use / 使用时机:** 把散落的项目资料按读者问题整理成可用的导航入口。

**Completion / 完成标准:** 资料导航、每项用途与来源位置，以及缺失或过期材料清单。

### Prompt / 提示词

```text
根据下面列出的项目资料，制作一份面向【目标读者】的资料导航。按读者要解决的问题组织，而不是按文件名堆砌。每个入口写明能回答什么、先读什么、原始文件或链接在哪里、内容是否已确认。不要复制全文；资料不足或冲突时标为待确认，最后列出最值得补充的缺口。

资料清单：
[粘贴文件、链接和简要说明]
```
